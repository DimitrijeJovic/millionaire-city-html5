Millionaire City HTML5 - Windows desktop version
=================================================

Start
  Double-click "Millionaire City HTML5.exe" (portable folder), or use the Start menu / desktop
  shortcut after running the installer. Chrome, Node.js, a server or an internet connection are
  not needed; the game files are inside the application folder.

Controls
  F11 switches full screen. Close the window to quit; progress is saved after every change.

Saved games
  %APPDATA%\Millionaire City HTML5\  (Local Storage of the application)
  This folder is outside the application folder. Deleting or replacing the application,
  or installing a newer version, does not touch it.

Updating
  There is no automatic update. Install the new version over the old one (installer), or replace
  the portable folder. Saved games stay in %APPDATA%.

Uninstalling
  Installer version: run "Uninstall.cmd" in the installation folder
  (%LOCALAPPDATA%\Programs\Millionaire City HTML5). It removes the program and shortcuts and keeps
  the saved games. Portable version: delete the folder.

Not signed
  The executable is the official Electron 44.10.0 runtime (checksum-verified) and is not
  code-signed, so Windows SmartScreen may ask for confirmation on first start.

Online features of the original game (friends, investments, Facebook credits) needed the original
server and are not available.
